# Diaco Print Standard

**Status:** DRAFT  
**Version:** 0.1

## Goal

Define one reusable Diaco print/print-preview behavior that can be invoked across projects.

## Approved rules already in force

- Printing is a reusable cross-project capability.
- Printable layout may be separate from screen layout.
- A project must preserve the selected printer, page size, margins, orientation, scaling, header/footer, pagination, and RTL/LTR behavior when those are part of the approved design.
- Print output must be verified, not assumed from screen rendering.
- Existing working print behavior must not be replaced casually.

## Not yet standardized

These details require a real approved reference:
- exact paper sizes/default
- header layout
- logo placement
- title/date/user placement
- footer layout
- page numbering style
- table borders and row density
- signature/stamp sections
- font family and print sizes
- margins
- print preview controls
- printer-selection workflow

## Promotion workflow

When the user says a print form is the standard:
1. inspect that exact implementation,
2. extract the reusable print contract,
3. record screenshots/files/paths if available,
4. define variations that are allowed,
5. promote this standard from DRAFT to ACTIVE.
